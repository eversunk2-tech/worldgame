# Review 서브에이전트 지침 (v2: 2D 학습형 RPG)

## 역할
Build 서브에이전트가 구현한 2D 학습형 온라인 롤플레잉 게임 v0.1이 `/Users/sungchul/Desktop/play1/spec.md`대로 동작하고 코드에 문제가 없는지 검증한다.
결과를 `/Users/sungchul/Desktop/play1/review.md`로 작성한다 (기존 review.md는 3D 버전이므로 덮어쓴다).

## 수정 범위
- 새로 만들거나 수정할 수 있는 파일: `review.md` 하나뿐이다.
- 소스 코드, `spec.md`, `CLAUDE.md`, `agents/` 폴더는 수정하지 않는다. 문제를 발견하면 고치지 말고 review.md에 기록한다.
- 검증용 임시 파일이 필요하면 `/private/tmp/claude-501/-Users-sungchul-Desktop-play1/01f9f636-e5fb-403d-bba2-0594e7925ed6/scratchpad` 아래에 만든다.
- git 커밋은 하지 않는다.

## 검증 절차
1. spec.md 전체를 읽고, 특히 구현 순서·완료 기준, 검증 방법, 확정된 결정 사항 절을 기준으로 삼는다.
2. 정적 검증
   - `npm install`, `npm run typecheck`, `npm test`, `npm run build`가 통과하는지 실행한다.
   - `src/shared` 아래에 phaser, document, window, localStorage 등 브라우저 의존성이 없는지 grep한다.
   - 파일 구조가 spec과 일치하는지, 삭제 대상 3D 파일이 남아 있지 않은지 확인한다.
3. 동작 검증
   - `npm run dev`로 개발 서버를 띄우고 브라우저 도구(`mcp__Claude_Browser__*`)로 접속한다.
   - spec의 브라우저 체크리스트를 한 항목씩 실제로 조작해 확인한다. 키 입력이 필요한 항목은 `javascript_tool`로 키 이벤트를 디스패치하거나 게임 상태를 읽어 확인해도 된다.
   - 전체 플레이 흐름을 끝까지 진행한다: 이름 입력 → 세계지도에서 서울 입장 → NPC 대화 → 미니게임(퀴즈·OX) 클리어 → 포인트 획득 → 몬스터 처치 → 파리 해금·입장 → 아바타 룸에서 아이템 구매·장착 → 도시 맵에서 장착 반영 확인 → 새로고침 후 복원.
   - 학습 콘텐츠 검토: 학습 카드와 퀴즈 문항의 사실 관계, 초등 5~6학년 수준 적합성, 오탈자를 확인하고 문제가 있으면 기록한다.
   - 콘솔 에러(`read_console_messages`)가 없는지 확인한다.
   - `node server/index.js`(포트 3100)로 프로덕션 서버를 띄우고 `/health`와 빌드된 게임이 뜨는지 확인한다.
   - 확인 후 서버 프로세스는 종료한다.
4. 코드 리뷰
   - spec의 코드 리뷰 포인트를 기준으로 본다.
   - 추가로: Scene 전환 시 리스너·타이머 누수, 프레임마다 객체 생성 등 성능 문제, 상태를 뷰에서 직접 수정하는 위반, 저장 데이터 검증·마이그레이션 누락, 명백한 버그.
5. spec의 확정 결정 사항이 임의로 변경되지 않았는지 확인한다.
