# Review 서브에이전트 지침

## 역할
Build 서브에이전트가 구현한 3D 온라인 롤플레잉 게임 v0.1이 `/Users/sungchul/Desktop/play1/spec.md`대로 동작하고 코드에 문제가 없는지 검증한다.
결과를 `/Users/sungchul/Desktop/play1/review.md`로 작성한다.

## 수정 범위
- 새로 만들 수 있는 파일: `review.md` 하나뿐이다.
- 소스 코드, `spec.md`, `CLAUDE.md`, `agents/` 폴더는 수정하지 않는다. 문제를 발견하면 고치지 말고 review.md에 기록한다.
- 검증용 임시 파일이 필요하면 `/private/tmp/claude-501/-Users-sungchul-Desktop-play1/01f9f636-e5fb-403d-bba2-0594e7925ed6/scratchpad` 아래에 만든다.
- git 커밋은 하지 않는다.

## 검증 절차
1. spec.md 전체를 읽고, 특히 6절(구현 순서·완료 기준), 7절(검증 방법), 9절(확정된 결정 사항)을 기준으로 삼는다.
2. 정적 검증
   - `npm install`, `npm run typecheck`, `npm run build`가 통과하는지 실행한다.
   - spec 7.1의 shared 순수성 검사(grep)를 실행한다: `src/shared` 아래에 three, document, window, localStorage 등 브라우저 의존성이 없어야 한다.
   - 파일 구조가 spec 3절과 일치하는지 비교하고, 누락·추가된 파일을 기록한다.
3. 동작 검증
   - `npm run dev`로 개발 서버를 띄우고 브라우저 도구(`mcp__Claude_Browser__*`)로 접속한다.
   - spec 7.2 브라우저 체크리스트를 한 항목씩 실제로 조작해 확인한다. 키 입력·마우스 드래그·시간 경과가 필요한 항목은 `javascript_tool`로 키 이벤트를 디스패치하거나 게임 상태를 읽어 확인해도 된다.
   - 콘솔 에러(`read_console_messages`)가 없는지 확인한다.
   - `node server/index.js`로 프로덕션 서버를 띄우고 `/health`와 빌드된 게임이 뜨는지 확인한다.
   - 확인 후 서버 프로세스는 종료한다.
4. 코드 리뷰
   - spec 7.3 코드 리뷰 포인트를 기준으로 본다.
   - 추가로: 게임 루프에서 프레임마다 객체를 새로 생성하는 등 성능 문제, 이벤트 리스너 누수, 상태를 뷰에서 직접 수정하는 위반, 저장 데이터 검증 누락, 명백한 버그.
5. spec 9절의 확정 결정 사항이 임의로 변경되지 않았는지 확인한다.
