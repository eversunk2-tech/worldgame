# Plan 서브에이전트 지침

## 역할
아래 요구사항을 바탕으로 3D 온라인 롤플레잉 게임의 첫 버전(v0.1) 계획을 작성하고 `/Users/sungchul/Desktop/play1/spec.md`로 저장한다.
코드를 작성하거나 다른 파일을 만들지 않는다. 수정 범위는 `spec.md` 하나뿐이다.

## 프로젝트 목표
캐릭터가 3D 맵을 돌아다니며 미션을 해결하고 레벨업하는 온라인 롤플레잉 게임.
첫 버전은 싱글플레이로 완성하되, 이후 멀티플레이(서버 동기화)를 붙이기 쉬운 구조로 설계한다.

## 사용자가 확정한 사항
- 기술 스택: 웹. Three.js(클라이언트) + Node.js(서버). 빌드 도구는 Vite 권장.
- 온라인 범위: v0.1은 싱글플레이. Node.js 서버는 정적 파일 서빙 정도로 두고, 이후 Socket.IO 등으로 확장할 접점만 남긴다.
- 그래픽: 로우폴리/박스 형태. 외부 3D 모델 에셋 없이 Three.js 기본 도형(Box, Cylinder, Sphere 등)으로 캐릭터·NPC·몬스터·맵을 구성한다.
- v0.1 포함 요소:
  1. 이동 + 카메라: WASD 이동, 마우스 드래그로 카메라 회전(3인칭), 점프, 바닥 충돌
  2. 미션 시스템: NPC에게 접근해 미션 수락, 목표 달성(예: 몬스터 N마리 처치, 특정 지점 도달), 완료 시 보상(경험치)
  3. 레벨·경험치: 경험치 획득, 레벨업, 레벨에 따른 스탯(체력, 공격력) 상승, HUD 표시
  4. 전투: 몬스터 배치, 근접 공격(키 입력), 몬스터 체력·간단한 추적 AI, 처치 시 경험치, 플레이어 피격·사망·리스폰

## spec.md에 반드시 포함할 내용
1. 개요와 v0.1 범위 (포함/제외 명시)
2. 기술 스택과 의존성 (버전은 주요 라이브러리만)
3. 파일/폴더 구조 (각 파일의 역할 한 줄 설명)
4. 핵심 시스템 설계: 게임 루프, 입력, 플레이어, 카메라, 맵, NPC/미션, 몬스터/전투, 경험치/레벨, HUD
   - 각 시스템의 데이터 구조(간단한 TypeScript 또는 JS 객체 형태)와 서로 간의 의존 관계
5. 멀티플레이 확장을 위한 설계 고려사항 (상태를 어디에 두고 어떻게 분리할지)
6. 구현 순서 (단계별 마일스톤, 각 단계의 완료 기준)
7. 검증 방법 (Review 단계에서 어떻게 동작을 확인할지: 실행 명령, 브라우저에서 확인할 체크리스트)
8. 위험 요소와 대안
